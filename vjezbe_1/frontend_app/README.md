https://rs-vjezbe-davor.onrender.com/

## HTTP zahtjevi prema backendu (`app.js`)

- `GET /jelovnik` – prikaz jelovnika
- `GET /narudzbe` – prikaz narudžbi
- `POST /narudzbe` – slanje nove narudžbe iz forme
